Recomendaciones antes de reportar

Para agilizar la labor de los rescatistas, asegúrate de proporcionar referencias claras y datos verdaderos. Si el animal se muestra agresivo debido al miedo, te sugerimos mantener una distancia prudente mientras llega el equipo de apoyo.

Nota: Si el caso involucra un accidente grave de tránsito o una emergencia vital, selecciona estrictamente el nivel de urgencia Crítico.
